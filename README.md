# Signal Book

GitHub Pages용 단일 파일 주식 대시보드입니다. AI · 로봇 · 원전 및 에너지 · 바이오 4개 테마의 국내·해외 231종목을 시세, 기술지표, 기업 분석과 함께 봅니다.

## 게시 방법

1. 이 폴더의 `dashboard-v2.html`(과 원하면 `index.html`)을 GitHub 저장소 루트에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**, `main`, `/ (root)`를 선택하고 저장합니다.

별도 빌드나 패키지 설치가 필요하지 않습니다. 화면 설정(테마·시장·워치리스트·보기 모드)은 방문자의 브라우저 `localStorage`에 저장됩니다.

`index.html`은 `dashboard-v2.html`로 자동 이동합니다.

## 시세 데이터

**2단 구조입니다.**

**1단 — 내장 스냅샷.** `refresh_quotes.py`가 231종목의 시세·52주 최고/최저·RSI(14)·20일선·60일선·1년치 일봉을 받아 `dashboard-v2.html` 안에 직접 써넣습니다. 이 값이 항상 존재하므로 네트워크가 없어도 화면이 비지 않습니다.

```bash
python3 refresh_quotes.py
```

파이썬 표준 라이브러리만 사용하며 API 키·서버·패키지 설치가 필요 없습니다. 몇 번을 실행해도 같은 결과를 만드는 멱등 스크립트입니다. 종목 목록은 `dashboard-v2.html`에서 직접 파싱하므로 대시보드에 종목을 추가하면 스크립트가 자동으로 따라갑니다.

**2단 — 브라우저 실시간 갱신.** 페이지를 열면 현재 화면에 보이는 종목(선택 종목 + 목록 상위 60개)의 시세를 다시 불러오고, 탭이 활성 상태인 동안 60초마다 갱신합니다. 성공하면 상단 배지가 `LIVE`로 바뀌고, 실패하면 내장 스냅샷 값을 그대로 유지한 채 스냅샷 경과 시간을 표시합니다. 스냅샷이 3일보다 오래되면 배지가 노란색으로 바뀌며 `refresh_quotes.py` 실행을 안내합니다.

Yahoo Finance는 CORS 헤더를 보내지 않아 정적 페이지에서 직접 호출할 수 없습니다. 그래서 브라우저 요청만 공개 리더(`r.jina.ai`)를 경유합니다. 리더가 죽어도 1단 데이터로 동작합니다.

RSI·이동평균은 받아온 일봉 종가로 직접 계산하며, 실시간 가격이 들어오면 마지막 종가를 갈아끼워 지표도 함께 움직입니다.

## 한국 종목 심볼 주의

`refresh_quotes.py`의 `KR_SYMBOLS` 표는 편의 목록이 아니라 **정확성 가드**입니다. Yahoo는 6자리 KRX 코드에 대해 `.KS`와 `.KQ` 양쪽 모두에 응답하는데, 틀린 접미사를 쓰면 오류가 아니라 **다른 종목의 1년치 데이터**가 그럴듯하게 돌아옵니다.

```
005930.KS = 273,750  (삼성전자, 정답)
005930.KQ =  84,400  (전혀 다른 종목)
058470.KQ =  70,300  (리노공업, 정답)
058470.KS = 219,500  (전혀 다른 종목)
```

56종목 전부 Yahoo 심볼 검색 엔드포인트(`KSC`=KOSPI / `KOE`=KOSDAQ)로 교차 확인했습니다. 국내 종목을 추가할 때는 표에 명시적으로 넣어야 하며, 빠뜨리면 스크립트가 추측하지 않고 에러로 멈춥니다.

## 차트

내장된 일봉으로 SVG 차트를 직접 그립니다. 20일·60일 이동평균 오버레이, 1M/3M/6M/1Y 구간, 마우스 크로스헤어를 지원합니다.

TradingView는 한국거래소 시세를 외부 임베드로 제공하지 않기 때문에, 예전에는 국내 60여 종목에 차트가 아예 없었습니다. 이제는 국내·해외 구분 없이 모두 차트가 나옵니다. 해외 종목은 `TradingView 고급 차트` 버튼으로 원본 위젯을 불러올 수 있고, 국내 종목은 TradingView 원본 링크를 함께 제공합니다.

## 화면

- **전체 테마** — 4개 테마 카드. 각 카드에 평균 등락률, 상승/전체 종목 수, 변동 폭 상위 2종목이 실시간으로 표시됩니다.
- **리스트 보기** — 좌측 종목 목록 + 우측 상세(3개 KPI, 차트, SWOT, 상승·하락 촉매).
- **스캔 보기** — 테마 전체를 한 표에서 비교. 현재가·등락률·52주 근접도·RSI·방향성·60일 스파크라인, 컬럼 헤더 클릭으로 정렬.
- **★ 워치리스트** — 테마와 무관하게 관심 종목만 모아 봅니다.
- **검색** — 현재 테마가 아니라 231종목 전체에서 찾습니다.
